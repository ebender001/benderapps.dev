About HeartChart

HeartChart is a visual tool for illustrating cardiac surgery cases on iPhone and iPad. You draw CABG graft configurations directly on a heart diagram, add associated procedures such as valve surgery, and export a clean PDF case summary for review or sharing.

It is built for surgeons, trainees, and educators who want a fast way to document operative coronary anatomy and procedural details in a clear visual format.

Key features

  • Draw CABG graft configurations on a heart diagram
  • Add associated non-CABG procedures such as valve surgery
  • Export professional PDF case summaries
  • Save cases for later reference (optional yearly subscription)
  • Simple workflow: create a case, add details, generate a PDF

Useful for

  • Surgical education
  • Operative planning discussions
  • Case review
  • Teaching conferences

Who it is for

Cardiac surgeons, trainees, and educators.

Important notes

HeartChart is a visualization and documentation tool only. It does not provide medical advice, diagnosis, or treatment recommendations and should not be used for clinical decision-making. Users are responsible for making sure anything they enter complies with applicable patient privacy requirements. Saving cases requires an optional yearly auto-renewing subscription managed through your Apple ID.
