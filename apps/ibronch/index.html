About iBronch

Bronchoscopy lets physicians see the trachea and the bronchi that supply the lungs, and it takes skill and patience to obtain the views needed for a complete study. There is a learning curve to the procedure.

iBronch uses images from real bronchoscopies to show typical views of a normal tracheobronchial tree. Because it is a simulation and does not involve a real patient, it is a way to get familiar with the images you should expect to see before you see them in practice.

Key features

  • Images from actual bronchoscopies
  • Typical views of a normal trachea and bronchial tree
  • Simulation with no patient involved

Who it is for

Trainees and clinicians learning bronchoscopy.
